This is a program to help train people piano keyboard skills using midi files and custom lessons.  The idea is taking the old typing or guitar hero style dropping symbols
to help people know when to press the key. It works as a VST3 program taking midi input from your midi keyboard used with the daw. 


TSF - tiny sound font player is incorporated into the plugin source via tsf.h and tsf.cpp which are under third party license as MIT licensed components. I will add a bit more
info and link them shortly.
